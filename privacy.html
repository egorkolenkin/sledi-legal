2. Прогресс и настройки

Находки, пройденные осмотры, выбранное дело, язык, звук и служебные счётчики сохраняются на устройстве для продолжения игры и работы её механик. Эти сведения автоматически не отправляются разработчику. Игрового аккаунта, серверного хранилища прогресса, покупок и встроенного чата в этой Android-версии нет. Отдельная аналитика игровых действий на сервер разработчика не отправляется.

Локальные сведения сохраняются до очистки данных приложения или его удаления. В Android-версии отключено системное автоматическое резервное копирование данных приложения.

3. Реклама и рекламная сеть

Бесплатная версия содержит рекламу Рекламной сети Яндекса и использует Yandex Mobile Ads SDK. Рекламный SDK инициализируется при запуске приложения. Межстраничные объявления могут показываться в перерывах между осмотрами и при повторной попытке после проигрыша. Просмотр рекламы за наводку запускается по выбору игрока; награда выдаётся после подтверждения рекламной сетью. Бесплатного переключателя отключения всей рекламы в приложении нет.

При подключении к интернету рекламная сеть может получать IP-адрес, технические сведения об устройстве, операционной системе и приложении, служебные идентификаторы и сведения о запросах, показах и взаимодействиях с рекламой. Эти сведения используются для предоставления рекламы, учёта её работы, безопасности и предотвращения злоупотреблений. IP-адрес может использоваться сетью для определения приблизительного региона. Игровой прогресс и письма поддержки приложение в рекламный SDK не передаёт.

В текущей конфигурации передаётся отказ от персонализации (userConsent=false), включён режим ограничений по возрасту, отключены отслеживание геопозиции и отправка App Ad Analytics. Разрешение Android AD_ID исключено из манифеста. Эти ограничения не означают полного отсутствия обработки технических сведений рекламной сетью.

Правила, основания и сроки обработки данных рекламной сетью, а также порядок обращений к ней описаны в политике конфиденциальности Яндекса. Разработчик не определяет сроки хранения данных на стороне Яндекса. Отказ от добровольного просмотра ролика за наводку не отключает обычные рекламные показы и уже выполненные обращения SDK.

4. Резервные копии

По команде игрока приложение экспортирует JSON-файл прогресса в выбранное через системный диалог место. Файл не шифруется приложением. Для импорта игрок сам выбирает файл и подтверждает замену прогресса. Общего доступа к хранилищу устройства игра не получает.

Если выбрано облачное хранилище, передачу и хранение файла выполняет выбранный игроком поставщик документов по собственным правилам. Экспортированные копии остаются до их удаления игроком; удаление приложения само по себе эти файлы не удаляет.

5. Обращения в поддержку

При самостоятельном обращении по email разработчик получает адрес отправителя, текст и добровольно приложенные материалы. Они используются для рассмотрения обращения, исполнения условий использования и применимых обязанностей по закону. Не отправляйте сведения, которые не нужны для решения вопроса, включая пароли, паспортные и платёжные данные.

Переписка хранится до решения вопроса, после чего удаляется, если дальнейшее хранение не требуется законом или для рассмотрения связанных требований. Удаление писем выполняется владельцем вручную. Для доставки и хранения почты используется Gmail; правила поставщика изложены в политике конфиденциальности Google. Приложение не отправляет письма автоматически.

6. Права и удаление данных

На email поддержки можно направить запрос о данных, обрабатываемых разработчиком, их уточнении, прекращении обработки или удалении в случаях, предусмотренных применимым законодательством. Для защиты от обращения постороннего лица может потребоваться соразмерное подтверждение принадлежности данных. Срок ответа и допустимые исключения определяются применимым законодательством.

Прогресс удаляется через системную очистку данных Android или удаление игры; перед этим при необходимости экспортируйте копию. Резервные файлы удаляются отдельно. По данным, которые рекламная сеть или поставщик хранилища обрабатывает самостоятельно, обращайтесь также к соответствующему поставщику. Удаление локального прогресса не удаляет автоматически сведения на стороне этих поставщиков.

7. Разрешения и безопасность

Приложение использует доступ к интернету, проверку состояния сети и служебные разрешения библиотек. Доступ к контактам, камере, микрофону, точной геопозиции и общему хранилищу не запрашивается. Все игровые сцены входят в установочный пакет. Для прогресса используется закрытое хранилище приложения; резервные файлы передаются только по команде игрока. Ссылки на документы открываются во внешнем браузере.

8. Страница политики и изменения

Документы размещены на GitHub Pages. При посещении страниц GitHub может обрабатывать IP-адрес и технические сведения запросов согласно политике GitHub. На этих страницах нет добавленных разработчиком рекламных блоков, аналитических счётчиков и форм сбора данных. Игровой прогресс хостингу не передаётся.
